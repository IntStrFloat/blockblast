## Короткое описание (до 80 символов)

> Расставляй блоки, собирай линии, лови комбо. Офлайн, без регистрации.

## Полное описание

> **Bloxx — головоломка с блоками, в которую залипаешь с первой партии.**
>
> Перетаскивай фигуры на поле 8×8 и собирай ряды и столбцы. Заполнил линию — она
> взрывается. Несколько линий разом и серии подряд дают комбо и взрывной рост очков.
>
> 🧩 Просто освоить — сложно отложить
> 🔥 Комбо, серии и рекорды
> 🎆 Сочные анимации и тактильный отклик
> 📈 Дневной стрик — играй каждый день и держи серию
> 📤 Делись рекордами с друзьями
> 🌙 Тёмная тема и две палитры блоков
> ✈️ Работает полностью офлайн, без регистрации и обязательной рекламы
>
> Вращать фигуры нельзя — думай наперёд. Игра окончена, когда ни одна из трёх фигур
> не помещается на поле. Сколько очков наберёшь ты?

## What's new (1.0.0)

> Первый релиз: классический режим 8×8, комбо и серии, рекорды, дневной стрик,
> две темы блоков, RU/EN.

## Артефакты сборки (2026-06-12, локально в dist/, не в git)

| Файл | ABI | Размер | Назначение |
|---|---|---|---|
| `dist/bloxx-v1.0.0-arm64.apk` | arm64-v8a | 46.3 МБ | **загрузка в RuStore** (покрывает ~98% активных устройств) |
| `dist/bloxx-v1.0.0-universal.apk` | все 4 | 107 МБ | эмулятор/тесты, старые armv7-устройства |

Команда arm64-сборки: `.\gradlew assembleRelease "-PreactNativeArchitectures=arm64-v8a"`.
Смоук release-сборки на эмуляторе пройден: Home → партия → drag-размещение (+4 очка) →
force-stop → «Continue · 4» (автосейв). Скриншоты: `store/smoke-*.png`.

## Чек-лист перед загрузкой

- [ ] APK подписан release-ключом (`credentials/release.jks` — **сделать бэкап ключа!**)
- [ ] Политика доступна по публичному URL (см. выше)
- [ ] Скриншоты: 5+ портретных (Home, игра с превью, очистка с похвалой, Game Over с рекордом, настройки)
- [ ] Иконка 512×512 (взять `assets/images/icon.png`, уменьшить)
- [ ] Анкета данных: данные не собираются, разрешение только VIBRATE
- [ ] Нет кнопок-заглушек в UI (IAP-кнопки скрыты флагом — проверено)

## Деплой политики конфиденциальности

⚠️ Статус на 2026-06-12: сервер `186.246.12.198` недоступен с машины сборки
(SSH на 22/443 — таймаут banner exchange; все порты отвечают TCP с ping 0мс —
похоже на сетевую заглушку/фильтр по пути, а не на живой хост). Файл готов:
`store/privacy.html`. Когда сервер будет доступен:

```bash
scp store/privacy.html root@186.246.12.198:/var/www/html/privacy.html
# при отсутствии веб-сервера: apt install -y nginx (webroot по умолчанию /var/www/html)
# проверить: http://186.246.12.198/privacy.html
```

URL уже прописан в настройках приложения (`src/app/settings.tsx → PRIVACY_URL`).
Альтернатива — GitHub Pages репозитория (Settings → Pages → деплой из ветки,
папка `/docs`; положить копию политики в `docs/privacy.html` и поменять PRIVACY_URL).

## Включение монетизации (после регистрации кабинетов)

Шаги и пакеты — `docs/specs/05-monetization.md`. Кратко: Yandex Mobile Ads
(`yandex-mobile-ads@8.x`) + RuStore Billing SDK, флаги в

пересобрать. Код экранов менять не нужно.

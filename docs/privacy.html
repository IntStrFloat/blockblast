Политика конфиденциальности приложения «Bloxx»

Действует с 13 июня 2026 г.

Политика описывает обработку данных в мобильной игре-головоломке Bloxx.

1. Анонимный профиль и лидерборд

Для участия в недельном рейтинге приложение создаёт анонимный идентификатор, никнейм и короткий tag. Электронная почта, телефон, настоящее имя, контакты, геолокация, фото и рекламный идентификатор не запрашиваются.

На сервер передаются никнейм, анонимный идентификатор, лучший игровой результат, seed партии, журнал игровых ходов и техническое время завершения. Журнал ходов используется только для проверки результата и защиты рейтинга от подмены.

2. Локальные данные

Текущая партия, настройки, локальный рекорд, streak, очередь несинхронизированных результатов и настройка аналитики хранятся на устройстве. Игра остаётся доступной без подключения к сети.

3. Аналитика

Приложение содержит локальную очередь минимальных событий взаимодействия. Отправка продуктовой аналитики на сервер в версии 1.1 отключена. Пользователь может полностью отключить аналитику в настройках; неотправленная очередь удаляется.

4. Сроки и передача

Данные рейтинга хранятся для работы недельных таблиц и расследования злоупотреблений. Данные не продаются и не передаются рекламным сетям. Сервер размещён по адресу 193.160.208.95.

5. Дети

Приложение не собирает контакты, местоположение, фото, голос, свободное описание профиля или иные чувствительные данные детей. Публичное общение между пользователями отсутствует.

6. Разрешения

Используется вибрация устройства для тактильного отклика. Другие чувствительные разрешения для работы игры не требуются.

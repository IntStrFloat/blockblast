# Block Blast v1 — Финишный план (атомарные задачи)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development — диспатч свежего субагента на задачу + двухэтапное ревью (spec → quality). Чекбоксы `- [ ]` — трекинг.

**Goal:** Довести игру от готового движка/сторов до играбельного релиза: drag-n-drop UI, джус, экраны, release APK, артефакты RuStore.

**Architecture:** Готово и зелено (91 тест): `core/engine` (чистый TS), `core/{storage,i18n}`, `ui/` (токены, AppText, примитивы), сторы `settings/scores/streak/monetization/game`, drag-каркас (`gridMath` worklet-математика, `DragContext`, `Block`). Остался UI-слой поверх: компоненты на Views+Reanimated (drag целиком на UI-потоке, спека 07), экраны, сборка.

**Tech Stack:** Expo SDK 56 / RN 0.85 / Reanimated 4 / gesture-handler 2 / zustand / MMKV 4 / expo-audio / expo-haptics / jest-expo. Перед кодом сверяться с https://docs.expo.dev/versions/v56.0.0/ (AGENTS.md).

**Прогресс по предыдущему плану** ([2026-06-12-v1-implementation.md](2026-06-12-v1-implementation.md)): Tasks 1–9 выполнены и закоммичены (по 6bd8eeb включительно). Этот план покрывает остаток (бывшие Tasks 10–15) атомарными кусками.

**Инварианты каждой задачи:** `npm test` и `npx tsc --noEmit` зелёные → conventional commit (рус.). `core/engine` не трогаем (если нужно — только вместе с тестами). Цвета — из `ui/theme.ts`, текст — `AppText`, строки — `core/i18n`. Правила перфа спеки 07 обязательны.

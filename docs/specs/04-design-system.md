# 04 — Дизайн-система и анимации

Статус: утверждено · Обновлено: 2026-06-12

## Визуальный язык

Референс — оригинальный Block Blast: тёмно-синий «космический» фон, яркие глянцевые блоки. Наш акцент: чуть глубже тьма (dark mode по умолчанию — норма ЦА), dopamine-цвета на фидбеке, glass-эффекты на оверлеях.

### Токены (`src/ui/theme.ts`)

```ts
colors: {
  bgTop: '#1B2A4A', bgBottom: '#0F1B33',     // вертикальный градиент фона
  boardBg: '#142142', cellEmpty: '#1E2F55',  // доска чуть светлее фона
  boardLine: '#0E1830',
  textPrimary: '#FFFFFF', textDim: '#8FA3C8',
  accent: '#FFC93C',                          // золото: счёт, корона, рекорд
  danger: '#FF5A5F',
  overlayScrim: 'rgba(8,14,28,0.72)',
}
```

### Палитра блоков (тема Classic)

6 цветов фигур, глянец отрисовывается одной ячейкой-компонентом (градиент верх-светлее + нижняя грань темнее + блик):

| colorId | base | пример |
|---|---|---|
| 1 | `#FF4D6D` | красный |
| 2 | `#FF9F1C` | оранжевый |
| 3 | `#FFD23F` | жёлтый |
| 4 | `#3DDC84` | зелёный |
| 5 | `#3FA7FF` | синий |
| 6 | `#B36BFF` | фиолетовый |

Тема Y2K-chrome (бесплатная вторая): серебристо-голографические базы `#C9D6E8 #F2A6D8 #9BE8E0 #B9B4F2 #FFE39B #A7C8FF` на фоне `#101018`.
Тема = объект `BlockTheme { cellColors: string[6], boardBg, bgTop, bgBottom }` — добавление темы не трогает компоненты.

### Типографика

- Заголовки/счёт: **Unbounded** (`@expo-google-fonts/unbounded`) — широкий дисплейный, идеален для цифр счёта.
- UI-текст: системный (SF/Roboto) через `AppText` с пресетами `title | score | body | caption`.
- Никогда не использовать `fontWeight` напрямую — только пресеты AppText (конвенция из прошлых проектов).

### Размеры

- Ячейка доски: `(width - 32) / 8`, gap 2px, радиус 4px. Доска — квадрат по ширине экрана с отступами 16.
- Трей: высота ~22% экрана, фигуры в масштабе 0.65.
- Минимальная цель тача: 44pt.

## Анимации (Reanimated 4, все на UI-потоке)

| Событие | Анимация | Длительность |
|---|---|---|
| Захват фигуры | scale 0.65→1.0 spring, подъём на −60px от пальца, лёгкая тень | 150мс |
| Возврат в слот | spring (damping 18, stiffness 220) | ~250мс |
| Размещение | ячейки фигуры: scale 1.15→1.0 | 120мс |
| Очистка линий | по ячейке: scale→0 + fade, стаггер 18мс от точки размещения волной | 250мс + стаггер |
| Частицы | 6–10 квадратиков цвета ячейки разлетаются с гравитацией (Reanimated, пул переиспользуемых вью) | 450мс |
| Похвала | баннер: scale 0.6→1 overshoot + fade out вверх | 700мс |
| Screen shake | translate доски ±3px, 2 цикла — только при 2+ линиях | 180мс |
| Новый рекорд | конфетти 24 частицы + counter roll | 1.2с |
| Каунтер счёта | бегущая цифра (анимированное число, шаг от дельты) | 300мс |
| Появление Home | блоки лого стаггером spring | 600мс, один раз |

Принципы: ничего не анимируем через JS-state; только `useAnimatedStyle` + shared values; стаггеры — `withDelay`. Частицы и конфетти — фиксированные пулы компонентов (без mount/unmount в горячем пути).

### Маскот «Капи» (см. [09-mascot.md](09-mascot.md))

- **Рендер — View-композиция, НЕ Skia**: маскот собирается из примитивов `View` (тело-градиент, уши, мордочка, аксессуары) + Reanimated-трансформы. Палитра — `mascotPalette` в `theme.ts` (лавандовый винил: корпус `#B3B9F2 → #7C84E6`, уши `#666FD8`, мордочка `#CDD2F9`, румянец `#F2A6D8`, обводка `#2B2440`).
- **Анимации** (всё на UI-потоке, мозг встаёт на паузу при любом drag):

| Событие | Анимация | Длительность |
|---|---|---|
| Idle/ходьба/моргание | bob + translateX слота, blink по интервал-таймеру | низкочастотно |
| Кормление | scaleX/scaleY пульс 1.0→1.12→1.0 + эмоция | ~120мс |
| Потеря (drop) | падение сквозь доску: bob+rotate, opacity→0 | 450мс |
| Возврат | opacity→1 + подскок bob spring | ~200мс |
| Левел-ап (reveal) | карточка-подарок scale overshoot + конфетти | 1.3с |

- **Эмоты** (`EmoteId`): пузырь над маскотом ~1.2с (`heart`, `sparkle`, …), `none` → не рендерится.

## Хаптика (expo-haptics)

| Событие | Паттерн |
|---|---|
| Захват | selection |
| Дроп валидный | impact light |
| Очистка 1 линии | impact medium |
| 2 линии | impact heavy |
| 3+ / комбо ≥3 | notification success |
| Game over | notification warning |
| Невалидный дроп | ничего (не наказываем) |
| Капи: кормление | impact light |
| Капи: левел-ап | notification success |
| Капи: потеря | impact medium |
| Капи: тап | selection |

## Звук (expo-audio)

Короткие синтезированные сэмплы (генерируются `scripts/gen-sounds.js` в WAV, см. репо): pickup (короткий клик), drop (мягкий тук), clear1/clear2/clear3 (нарастающие мажорные арпеджио — питч растёт с комбо), gameover (нисходящий), record (фанфара-арпеджио). Маскот «Капи» (09): feed (мягкий «ам»), levelup (короткая фанфара), lost (нисходящий блип). Все ≤400мс, ≤50КБ. Предзагрузка при входе в игру, polyphony — переиспользуемые плееры. Звук маскота гейтится настройкой и не играет на drag-пути.

# 13 — Achievements map (карта достижений)

Статус: черновик на ревью · Обновлено: 2026-06-20
Родитель: [10-progression.md](10-progression.md) · Связь: [11-progression-core](11-progression-core.md) (данные), [12-game-themes](12-game-themes.md) (цвета миров), [01](01-screens.md), [07](07-performance.md).

Отдельный экран-«дорога»: визуализирует Уровень Игры, миры и награды. Только чтение прогрессии. Неблокирующий, оффлайн, не в горячем игровом цикле.

## 1. Scope

- Роут `app/map.tsx` + входы (чип уровня на Home, кнопка на Game Over).
- Чистая деривация узлов дороги из `progression` (тестируемо).
- Рендер дороги (узлы миров/косметики/пустые, текущая позиция Капи, стилизованный гэп).
- **Не** входит: изменение прогрессии (11), каталог тем (12).

## 2. Деривация узлов (чистая логика)

```ts
// features/progression/logic/map.ts (логика рядом со стержнем, без RN)
export type NodeKind = 'world' | 'cosmetic' | 'helper' | 'empty';
export type NodeState = 'done' | 'current' | 'locked';

export interface MapNode {
  level: number;
  kind: NodeKind;
  state: NodeState;
  reward?: LevelReward;     // из rewardForLevel
  themeId?: string;         // для kind==='world'
  approachingThemeId?: string; // тонировка отрезка к ближайшему запертому миру (goal-gradient)
}

export function deriveMapNodes(
  lifetimePoints: number,
  fromLevel: number,        // окно рендера (виртуализация)
  toLevel: number,
  cfg?,
): MapNode[];
```
- `state`: `level < currentLevel` → done; `=== currentLevel` → current; `>` → locked.
- `approachingThemeId`: на узлах между текущим уровнем и `nextWorldLevel` проставляется themeId грядущего мира → UI тонирует отрезок (стилизованный гэп, 10 §7).
- `kind` из `rewardForLevel` (world/cosmetic/helper) или `empty`.

## 3. Экран и навигация

- `app/map.tsx` — роут (expo-router), доступ:
  - Home: тап по **чипу Уровня Игры** (уровень + бар) → переход на карту.
  - Game Over: кнопка «Карта» рядом с «+уровни за партию».
- Лист прокручиваемый; стартовая прокрутка — к текущему уровню (Капи в центре).

## 4. Рендер дороги

- Вертикальная/серпентинная дорога; **виртуализация** длинного списка (рендерим окно `fromLevel..toLevel` вокруг текущего; подгрузка при скролле).
- **Узел-мир** — крупный, в палитре своего мира (`useActiveTheme`/каталог 12); locked → silhouette/greyscale + замок; done → полноцвет; подпись (название мира, i18n).
- **Промежуточный узел** — мелкий; cosmetic → иконка предмета; helper → иконка помощника; empty → простой.
- **Текущая позиция** — Капи на узле `current` (переиспользуем рендер `Mascot` в статичной позе) + бар «до следующего уровня» (`pointsInLevel/pointsToNext`).
- **Стилизованный гэп** — отрезок к ближайшему запертому миру тонируется `approachingThemeId`.

## 5. Взаимодействие

- Тап по узлу → неблокирующий тултип/лист: уровень, награда, для мира — «новый дизайн». Для **открытой** темы-мира — кнопка «Сделать активной» (`setActiveTheme`, 12) либо ссылка в Settings.
- Никаких блокировок/попапов, чистый просмотр.

## 6. Доступность и перф (07/14)

- reduce-motion: без анимации дороги/Капи на карте (статичный кадр).
- Узлы различимы формой+иконкой, не только цветом; цели тача ≥44pt.
- Экран — отдельный роут, не в drag-пути; виртуализация удерживает память/fps на длинной дороге; Капи на карте — лёгкая статичная композиция (не полный мозг-тик).

## 7. i18n

- `map.*` (заголовок, «до следующего уровня», подписи состояний), `themes.*` (имена миров, общий ключ с 12). Нейтральный UI-тон.

## 8. Тесты

- `deriveMapNodes`: корректные `state` относительно текущего уровня; `kind`/`reward` из конфига; мировые узлы с themeId; `approachingThemeId` только на отрезке до `nextWorldLevel`; окно виртуализации (fromLevel..toLevel) не выходит за границы.
- Навигация: вход с Home/GameOver монтирует экран; стартовый скролл к текущему уровню (логика выбора окна).

# 09 — Профиль, недельный рейтинг и retention

Статус: реализовано в v1.1 · Обновлено: 2026-06-13

## Профиль

- При первом запуске локально создаётся безопасный никнейм и временный tag.
- Игра не требует формы регистрации и полностью работает без сети.
- При подключении сервер создаёт анонимный профиль, выдаёт Bearer token и неизменяемый tag.
- Никнейм можно изменить; сервер повторно валидирует значение. Фото, bio, чат, контакты и social graph отсутствуют.

## Недельный рейтинг

- Граница недели: понедельник 00:00 UTC.
- Рейтинг определяется одним лучшим проверенным результатом игрока за неделю.
- При равенстве выше игрок с меньшим числом ranked-партий, затем достигший результата раньше.
- Сервер выдаёт одноразовые tickets с seed. Клиент записывает только успешные ходы.
- На первом Game Over proof замораживается. Rewarded revive не увеличивает ranked score.
- Сервер повторно проигрывает все ходы через тот же `core/engine`; изменённый score и повторный ticket отклоняются.
- Без сети результат остаётся в bounded queue (до 20) и отправляется позже.

## Retention

- Daily Challenge использует общий seed из даты и появляется после трёх обычных партий.
- Home показывает недельный personal best и мягкую персональную цель без штрафов за пропуск.
- Аналитика хранится локально, типизирована и отключается пользователем. В production v1.1 отправка analytics на сервер выключена.
- Запрещены fake players, P2W, loot boxes, guilt-copy и обязательные уведомления.

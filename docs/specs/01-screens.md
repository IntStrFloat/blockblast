# 01 — Экраны и фичи

Статус: утверждено · Обновлено: 2026-06-12

Навигация: expo-router, stack. Игра — одна основная активность, всё остальное лёгкие экраны.
Game Over и Pause — **оверлеи внутри игрового экрана**, не отдельные роуты (мгновенное появление, нет перехода навигации).

## Карта роутов

| Роут | Экран | Назначение |
|---|---|---|
| `/` | Home | Вход, продолжить/новая игра, рекорд, стрик |
| `/game` | Game | Основной геймплей + оверлеи Pause / GameOver |
| `/settings` | Settings | Звук, вибро, тема, язык, тон похвал, аналитика, политика |
| `/leaderboard` | Leaderboard | Недельный рейтинг по лучшему результату игрока |

## Home (`/`)

- Логотип-надпись (анимированные блоки складываются в лого при входе — один раз, лёгкая стаггер-анимация).
- Кнопка **Play**: если есть сохранённая партия — «Продолжить» (+ счёт), вторая кнопка «Новая игра» (с подтверждением, т.к. сбрасывает партию).
- **Best score** с короной.
- **Стрик** (огонёк + число дней) — виден только если стрик ≥ 1. Ненавязчиво: без попапов, без guilt-механик.
- Иконка настроек (вверху слева), изменяемый никнейм и постоянный tag (вверху справа).
- Карточка недельного рейтинга: место, лучший результат недели, переход к таблице.
- Daily Challenge показывается после трёх завершённых партий, без блокирующего попапа.
- Фон — общий с игрой (тёмно-синий градиент), никакой рекламы на Home.

## Game (`/game`)

Зоны сверху вниз:
1. **Хедер**: счёт (анимированный каунтер), best (маленько, с короной), кнопка паузы.
2. **Слой «Капи»**: тонкая полоса над доской — чип уровня (слева), маскот, мягкие помощники (справа). Монтируется только при включённом тумблере. Детали — [09-mascot.md](09-mascot.md).
3. **Доска 8×8**: центр экрана, занимает ~ширину экрана минус отступы.
4. **Трей**: 3 фигуры в слотах, уменьшенный масштаб (~0.65), неиспользуемые (не влезающие никуда) — приглушены.

Фичи геймплея (детали правил — [03-game-engine.md](03-game-engine.md)):
- Drag-n-drop фигуры из трея: при захвате фигура увеличивается до 1.0 и поднимается над пальцем (~60px), чтобы палец не закрывал её.
- **Превью**: валидная позиция подсвечивается ghost-блоками; линии, которые будут очищены, подсвечиваются цветом фигуры.
- Невалидный дроп → фигура спрингом возвращается в слот.
- Очистка линий: каскадная анимация ячеек (scale+fade со стаггером от точки размещения), частицы.
- **Похвалы**: при очистке ≥1 линии — баннер по тирам (1 линия Good / 2 Great / 3 Amazing / 4+ Unbelievable; combo ≥3 добавляет огонь). Тон текста зависит от настройки (см. 06).
- **Combo-индикатор**: серия очисток подряд — счётчик с огоньком у счёта.
- Хаптика + звук на: захват, валидный дроп, очистку (сила растёт с тирами), game over.
- **Капи (маскот)**: интерактивный питомец на слое над доской — кормление раз в день, перетаскивание, мягкие помощники (подсказка хода / замена непомещаемой фигуры). Интро первого захода вплетено в первую партию неблокирующе (скип в любой момент). Полностью описан в [09-mascot.md](09-mascot.md).

Оверлей **Pause**: продолжить, заново, домой, быстрые тогглы звук/вибро. Блюр/затемнение фона.

Оверлей **Game Over**:
- Появляется после короткой паузы (~0.8с) с анимацией заполнения доски серым.
- Счёт, best (если побит — «Новый рекорд!» + конфетти).
- **Revive** (1 раз за партию): rewarded-видео → очистка всей доски, счёт сохраняется. Если реклама выключена/недоступна — кнопка скрыта.
- «Сыграть ещё», «Домой».
- **Поделиться** — карточка результата (см. 06).
- Влияние результата на недельный рейтинг: новый недельный рекорд или сохранение текущего.
- Interstitial-реклама: после закрытия Game Over, по частотным правилам ([05-monetization.md](05-monetization.md)). Никогда не во время геймплея.

## Settings (`/settings`)

- Звук (вкл/выкл), Вибрация (вкл/выкл).
- **Показывать Капи** (вкл по умолчанию): слой маскота над доской. Выкл → слой/мозг/помощники не монтируются, прогресс Капи сохраняется (см. [09-mascot.md](09-mascot.md)).
- Тон похвал: «Классика» / «Мемный» (Gen Z тексты, см. [06-audience.md](06-audience.md)). По умолчанию — Классика.
- Тема блоков: Classic + купленные/будущие скины (v1: Classic + 1-2 бесплатные палитры).
- Язык: системный / RU / EN.
- **Убрать рекламу** (IAP) + «Восстановить покупки».
- Ссылки: политика конфиденциальности, версия приложения.
- Отправка продуктовой аналитики: локальный opt-out удаляет неотправленную очередь.
- Сброс рекорда (с подтверждением) — в самом низу.

## Leaderboard (`/leaderboard`)

- Недельная таблица сортируется по одному лучшему результату каждого игрока.
- При равенстве очков выше игрок с меньшим числом попыток, затем более ранний результат.
- Личный результат закреплён отдельно, даже если он вне top-100.
- При отсутствии сети отображается последний кэш; основная игра остаётся доступной.

## Явно НЕ в v1.1 (отложено)

- Adventure/levels-режим, публичный чат, социальный граф, награды с преимуществом и турниры с призовым фондом.

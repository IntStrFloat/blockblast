# 06 — Целевая аудитория и фишки (Gen Z / Gen Alpha)

Статус: утверждено · Обновлено: 2026-06-12
Источник: отчёт ресерч-субагента по ЦА (полные данные и источники — в истории проекта; ключевое — здесь).

## Портрет ЦА

- Block Blast: 368 млн загрузок (2025), ~70 млн DAU. Аудитория **двойная**: костяк казуального жанра — 25–44 (61% женщины) + вирусная Gen Z-волна из TikTok. Россия — в топ-6 рынков.
- Сессии: ~12 мин, 2–3 раза в день; транспорт, очереди, перед сном. **Оффлайн обязателен.**
- Gen Z/Alpha: внимание ~8 сек, 52% платящих (выше среднего), платят за **косметику, не за преимущество**.
- Уходят из-за: навязчивой рекламы (36%), форс-туториалов, регистрации до игры, P2W, корпоративного тона.

## Принципы (обязательны для всех фич)

1. **Мемы — косвенно, не в лоб.** Никаких «skibidi mode». Пасхалка на 13 337 очков — свои поймут, остальные улыбнутся.
2. **Старт за 2 касания без единого попапа.** Без регистрации, без форс-туториала (обучение — 3 подсказки прямо в первой партии, скипаются касанием).
3. **Только косметика, ноль P2W.**
4. Дерзкий контент — **только опционально** (переключатель тона), по умолчанию нейтрально: не отпугиваем 25–44. **Документированное исключение (маскот «Капи», [09](09-mascot.md)):** у Капи всегда включён *лёгкий* ироничный голос, но лишь в двух текст-моментах (интро первой партии и реплика потери); жёсткий Gen-Z-сленг по-прежнему только под тумблером «Дерзкий».
5. Шеринг-карточка — личный результат, не реклама приложения.
6. Тон рунета: ироничный, свойский, абсурдизм > прямых мемов.

- Ночной режим поведения (после 22:00 — тише и спокойнее).

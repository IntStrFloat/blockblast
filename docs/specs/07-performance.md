# 07 — Производительность

Статус: утверждено · Обновлено: 2026-06-12
Цель: стабильные 60fps на средних Android (класс Galaxy A54 / бюджетники 2022+) и любых iPhone. Игра «лёгкая»: холодный старт < 2с, APK без лишних нативных модулей.

## Бюджеты

| Метрика | Бюджет |
|---|---|
| Кадр во время drag | ≤ 16мс, ноль проходов через JS-мост |
| Re-render'ов React во время drag | 0 |
| Re-render при размещении | только изменившиеся ячейки (memo) |
| Холодный старт → Home | < 2с на среднем Android |
| Размер release APK (arm64) | < 30 МБ |
| Нативные зависимости сверх Expo | только mmkv (+ ad/iap SDK при включении флагов) |

## Решение по рендеру: Views + Reanimated (не Skia)

Ресерч подтверждает: 64 мемоизированных View держат 60fps; деградация возникает только при React-управляемых массовых анимациях. У нас **все** анимации — shared values на UI-потоке (transform/opacity, без layout), поэтому Skia не нужен. Это экономит нативную зависимость и упрощает сборку.
**Upgrade path** (если профилирование покажет дропы на бюджетниках): перенести слой доски на `@shopify/react-native-skia` (Atlas API, 1 draw call) — контракт `PlacementEvent` это позволяет без изменения движка и сторов.

## Правила (обязательные, проверяются на ревью)

1. **Drag целиком на UI-потоке**: `Gesture.Pan()` worklets; позиция, scale, подъём — shared values; расчёт клетки под пальцем — worklet-функция; превью — shared values, которые читают `useAnimatedStyle` ячеек. `runOnJS` — ровно один раз, на дроп.
2. **Ячейка доски — `React.memo`**, пропсы примитивные (`colorId`, `size`). Доска перерисовывает только изменившиеся ячейки (zustand-селектор по ячейке либо один массив + memo-сравнение).
3. Никаких inline-функций/объектов в пропсах горячих компонентов; обработчики — `useCallback`.
4. **Анимации только transform/opacity** (composited): никаких анимируемых width/height/layout-свойств.
5. Частицы/конфетти — **фиксированный пул** переиспользуемых вью (без mount/unmount в горячем пути), максимум 24 частицы.
6. Звуки — предзагрузка `expo-audio` при входе в игру; `seekTo(0); play()` — без создания плееров в геймплее.
7. MMKV-записи — на дроп (синхронный MMKV дешёвый), но сериализация партии — не чаще раза в ход.
8. Hermes + New Architecture (дефолт SDK 56). `react-compiler` включён в шаблоне — оставляем.
9. Никаких `console.log` в горячем пути (drag/place) даже в dev.

## Проверка

- Dev: Perf monitor (`adb shell dumpsys gfxinfo`), Reanimated debug; ручной тест на эмуляторе + реальном устройстве.
- Релиз: обязательный прогон release-сборки (JS-производительность в dev-режиме нерепрезентативна).

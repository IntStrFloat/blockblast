# 17 — Adventure-режим (реверс оригинала Block Blast)

Полные функциональные требования оригинального Adventure-режима Block Blast (Hungry Studio, `com.block.juggle`) для интеграции аналога в наш клон. Документ собран из двух источников: покадровый анализ скриншотов оригинала (5 экранов, июль 2026) и открытые описания/гайды. Каждый пункт помечен уровнем достоверности:

- **[S]** — подтверждено скриншотами (факт).
- **[W]** — подтверждено веб-источниками (официальное описание стора, гайды).
- **[A]** — обоснованное допущение (реверс-инжиниринг поведения; при интеграции решаем сами).

> ⚠️ Веб-источники по Block Blast сильно замусорены SEO-статьями (упоминания «монет», «3 звёзд», «power-ups» почти наверняка выдуманы и относятся к другим играм). Всё, что противоречит скриншотам, отброшено. Ядро документа — скриншоты.

---

## 1. Суть режима

Adventure — второй игровой режим рядом с бесконечным Endless: **последовательность конечных уровней с целью**, объединённых в «сезон». Каждый пройденный уровень закрашивает одну клетку **пиксельной мозаики** (силуэт животного). Полностью собранная мозаика = завершённый сезон = **кубок (trophy)**. [S][W]

Ключевые отличия от Endless:

| Аспект | Endless | Adventure |
|---|---|---|
| Конец партии | game over по очкам | уровень выигран/проигран по цели |
| Цель | максимум очков | набрать N очков ИЛИ собрать N кристаллов [S] |
| Блоки | многоцветные | **монохромные** (один цвет на уровень/мир) [S] |
| Доска на старте | пустая | может быть **предзаполнена** блоками и клетками-кристаллами [S] |
| Визуал | тема приложения | **своя тема уровня** (пример: коричнево-деревянная «rainforest») [S] |
| Мета-прогресс | рекорд | мозаика сезона + кубки [S][W] |

Позиционирование оригинала: «Explore the rainforest, meet rare animals» — сезоны тематически связаны с животными тропического леса; мозаика — силуэт животного, который «открываешь». [W]

## 2. Экраны и навигация

### 2.1 Экран «Adventure» (хаб сезона) [S]

Вход — с Home (кнопка/баннер Adventure). Состав сверху вниз:

1. **Хедер**: кнопка «назад» (←) слева, заголовок «Adventure» по центру. Фон — сплошной синий (своя палитра режима, не тема Endless).
2. **Кубок**: тёмный силуэт кубка со звездой + подпись «Take part in the Adventure and win the trophy.» Кубок тёмный/погашенный, пока сезон не завершён; предположительно загорается цветом по завершении. [S][A]
3. **Мозаика сезона**: пиксельная карта из квадратных тайлов (~90–110 тайлов, форма — силуэт животного). Каждый тайл = один уровень сезона.
   - Непройденные тайлы — тёмные.
   - Пройденные — закрашены акцентным цветом (на скрине 4 виден один закрашенный оранжевый тайл). [S]
   - Часть тайлов выделена **красно-оранжевой рамкой** — маркированные уровни (~15–20% от всех, распределены по карте). Интерпретация: **milestone/особые уровни** — либо уровни с кристаллами/наградой, либо повышенной сложности. [S][A]
   - Порядок закраски: уровни проходятся строго последовательно; закрашивается «следующий» тайл карты (снизу вверх по силуэту, судя по скрину 4, где закрашен нижний тайл). [S][A]
4. **CTA-кнопка**: зелёная пилюля «Level N» — текущий (следующий непройденный) уровень. Тап = старт уровня. [S]

Экрана «выбора уровня» нет: **линейная прогрессия, играть можно только текущий уровень**. [S][A]

### 2.2 Экран уровня (геймплей) [S]

Отдельный визуальный скин, не совпадающий с Endless:

1. **Хедер**: назад (←) слева, шестерёнка (настройки/пауза) справа. Заголовок уровня вверху едва виден (замылен на скринах — вероятно «Level N» мелким текстом).
2. **Панель цели** (по центру под хедером), два варианта:
   - **Score-цель**: горизонтальный прогресс-бар с радужной градиентной заливкой; справа круглый бейдж с числом-целью (пример: 128). Бар заполняется слева направо по мере набора очков. [S]
   - **Кристаллы-цель**: иконка кристалла (голубой ромб со свечением/искрами) + число оставшихся (пример: 3). Декремент при сборе. [S]
3. **Доска 8×8** в рамке темы уровня (коричневая деревянная рамка, тёмно-коричневые клетки, лёгкие «пылинки»-частицы на фоне). Может стартовать с предзаполненными блоками и **клетками-кристаллами** (золотая клетка с голубым ромбом внутри). [S]
4. **Трей фигур**: до 3 фигур, стандартные правила «поставь все 3 — получи новые». Все фигуры **одного цвета** (зелёные на скринах). Фигура может нести **кристалл** в одной из своих клеток (скрин 5: L-фигура с кристаллом). [S]

### 2.3 Экран/оверлей «Уровень пройден» [S]

Переходное состояние поверх игрового экрана (скрин 3):

1. Фон и доска затемняются/обесцвечиваются (панель цели и трей гаснут).
2. Появляются чипы **«Lv.1» (синий, слева) → «Lv.2» (жёлтый номер, справа)** над оранжевым прогресс-баром, бар заполняется до конца — визуализация перехода на следующий уровень. [S]
3. **Конфетти из цветных блоков** (квадраты в цветах палитры игры + мелкие ромбики-частицы) сыплется сверху с вращением и разлётом. [S]
4. Автопереход (или тап) → экран результата с мозаикой (2.4).

### 2.4 Экран результата (мозаика после уровня) [S]

Полноэкранный, синий фон:

1. Назад (←) сверху.
2. **Логотип Block Blast** (в нашем случае — свой логотип).
3. **Мозаика сезона** с только что закрашенным тайлом (закраска нового тайла анимируется: тайл «вспыхивает»/влетает). [S][A-анимация]
4. Пилюля **«Daily Goal»** с прогрессом N/5 — дневная цель (у нас 5 уровней, см. §6); под ней — DailyBonusMoment, если только что выдана ступень дейли-бонуса (спека 14 §8). [S]
5. Подпись **«Finish the season and full mosaic!»** — прямое подтверждение терминов «сезон» и «мозаика». [S]
6. Оранжевая CTA **«Next Level»** с иконкой кубка — сразу в следующий уровень (цикл без возврата в хаб). [S]
7. Счётчик **«Consecutive Clearances N»** — серия уровней, пройденных подряд (без поражения / за сессию / за день — точная семантика не видна; см. §6). [S]

### 2.5 Экран/оверлей поражения [A]

На скринах нет. По механике жанра и упоминаниям в гайдах:

- Условие поражения: нет места для любой из текущих фигур **до** выполнения цели. [W]
- Оверлей «Level Failed» с кнопками **Retry** (перезапуск уровня с исходного состояния) и выход в хаб. [A]
- В оригинале вероятен ревайв за рекламу (у нас — за флагом монетизации, см. §10). [A]
- Прогресс мозаики при поражении не теряется; сбрасывается только Consecutive Clearances. [A]

### 2.6 Экран завершения сезона [W][A]

На скринах нет (сезон не завершён). Реконструкция:

- Полная мозаика «оживает»: силуэт раскрашивается в полноценную пиксель-арт картинку животного (reveal). [A]
- Вручение **кубка**: кубок на хабе загорается, целебрация (конфетти, фанфары). [W]
- Кубки складываются в **коллекцию/галерею трофеев** — их можно пересматривать («completed trophies remain visible in your achievement gallery»). [W]
- После завершения открывается **новый сезон**: новая мозаика (другое животное), уровни продолжаются со следующего номера (сквозная нумерация — в источниках упоминается 1000+ уровней, т.е. номер уровня не сбрасывается). [W][A]

## 3. Правила уровня (геймплей-контракт)

1. **База** — те же правила, что в Endless: доска 8×8, дроп фигур из трея по 3, очистка полных строк/столбцов, комбо за последовательные очистки. [S][W]
2. **Цель уровня** (одна из):
   - `score`: набрать ≥ X очков (X растёт с номером уровня; уровень 1 ≈ 128). Победа — в момент достижения X. [S]
   - `jewels`: собрать N кристаллов. Кристалл сидит в клетке доски (предзаполненной или принесённой фигурой); собирается, когда **строка/столбец с этой клеткой очищается**. [S][A-механика сбора]
3. **Стартовая раскладка**: у уровня есть предопределённый лейаут предзаполненных клеток (обычных и кристальных). Ранние уровни — пустая доска. [S]
4. **Генерация фигур**: скорее всего скриптованная/сидированная последовательность на уровень (для управляемой сложности и воспроизводимости) — в нашей реализации: сид на уровень + возможность подмешивать фигуры с кристаллом, когда цель `jewels`. [A]
5. **Поражение**: невозможность поставить ни одну из фигур трея до выполнения цели. Лимита ходов/времени на скринах нет; таймеры из SEO-гайдов считаем недостоверными для базовой версии. [A]
6. **Очки внутри уровня** не идут в рекорд Endless и (решение для нас) конвертируются в общий прогресс Уровня Игры по правилам спеки 11 либо не конвертируются вовсе — см. «Открытые вопросы».

## 4. Прогрессия сложности и новые механики по уровням

Из скриншотов и источников (агрегировано, [S]+[W]+[A]):

| Диапазон | Что происходит |
|---|---|
| Уровень 1–5 | Обучение: пустая доска, простая score-цель (~100–200 очков), крупные удобные фигуры. Уровень 1 проходится за 3–6 дропов. [S] |
| ~5–15 | Появляются предзаполненные раскладки; score-цели растут. [A] |
| ~10–20 | **Новая механика: кристаллы (jewels)** — сначала 1–3 кристалла на предзаполненных клетках, потом кристаллы в фигурах. [S — уровень с 3 кристаллами явно ранний] |
| Дальше | Рост числа кристаллов, более «тесные» стартовые раскладки, комбинированное давление (мало свободного места + цель). [W][A] |
| Поздние (по гайдам) | «Obstacles, special block types» — доп. типы клеток-препятствий (например, клетки, требующие двойной очистки, лёд/ящики и т.п.). Точный список из скринов не подтверждён — для v1 достаточно score+jewels, остальное закладываем расширяемым типом клетки. [W][A] |
| Milestone-уровни (красная рамка на мозаике) | Каждые ~5–7 уровней; повышенная сложность и/или гарантированные кристаллы. [S][A] |

Сезон = число уровней, равное числу тайлов мозаики (**~90–110 уровней на сезон** по подсчёту тайлов на скрине). [S]

Общая длительность контента: в оригинале сезоны идут один за другим, суммарно тысячи уровней («5000+ levels» в описаниях) — практически бесконечный конвейер. [W]

## 5. Мозаика и сезон

1. Мозаика — пиксельный силуэт (животное сезона), тайл = уровень. [S][W]
2. После победы на уровне закрашивается ровно один тайл; порядок детерминированный. [S]
3. Milestone-тайлы визуально выделены рамкой уже на старте сезона (игрок видит, где «особые» уровни — мотивация дотянуться). [S]
4. Полная мозаика = конец сезона → reveal картинки + кубок → новый сезон с новой мозаикой. [S(«Finish the season and full mosaic!»)][W][A-детали]
5. Сезон **не привязан к календарю** (никаких таймеров на скринах): «сезон» = глава контента, а не временное событие. [A]

## 6. Дневная цель и серия

1. **Daily Goal: 5 levels** — пройти `ADVENTURE_CONFIG.dailyGoalLevels` (= 5; у оригинала 10 — снижено ради досягаемости казуалом, retention фаза 1) уровней Adventure за календарный день. Показывается на экране результата, на AdventureEntryCard (Home, мини-прогресс «Сегодня: 3/5») и в DailyCard. **Награда: ступень 2 дейли-бонуса — гарантированный дроп (спека 14 §6–7).** Победа уровня также поддерживает стрик (`markPlayedToday`) и первую победу дня (ступень 1). [S][A-награда]
2. **Consecutive Clearances** — счётчик уровней, пройденных подряд. Инкремент за каждую победу, сброс при поражении (наиболее вероятная семантика; альтернатива — «за сегодня»). Отображается на экране результата. [S][A-семантика]
3. В комьюнити встречается челлендж «consecutive daily wins» — серия дней с выполненной дневной целью; как отдельный счётчик на скринах не виден. [W]

## 7. Награды

| Событие | Награда |
|---|---|
| Победа на уровне | +1 тайл мозаики; продвижение Lv.N → Lv.N+1 [S] |
| Milestone-уровень | усиленная целебрация / гарантированные кристаллы (точно не подтверждено) [A] |
| Daily Goal 5 уровней | ступень 2 дейли-бонуса: гарантированный дроп (заряд/косметика/rare, спека 14) [A] |
| Полная мозаика (сезон) | **Кубок** + reveal арта животного; кубок навсегда в галерее трофеев; **эксклюзивная косметика Капи** (`SEASON_REWARDS`, retention фаза 3) [S][W][A] |
| Все сезоны | Конца нет: следующий сезон всегда есть (контент-конвейер) [W] |

Никаких монет, магазина, звёзд за уровень в оригинальном Adventure на скринах нет — SEO-упоминания игнорируем. [S]

## 8. Анимации, звук, хаптика (для нашей дизайн-системы, спека 04)

Подтверждено скринами и реконструировано:

1. **Заполнение прогресс-бара цели** — плавная анимация прироста при каждом начислении очков; бейдж с числом пульсирует при апдейте. [S][A]
2. **Сбор кристалла** — кристалл вылетает из очищенной клетки к счётчику цели (fly-to-counter), счётчик декрементится с bounce. [A, стандарт жанра]
3. **Победа на уровне**: доска гаснет (desaturate + dim), чипы Lv.N → Lv.N+1 + оранжевый бар заполняется, **блочное конфетти** сверху (цветные квадраты с вращением, гравитация — переиспользуем нашу систему BURST_MOTION/ClearBurstLayer). [S]
4. **Закраска тайла мозаики** на экране результата: короткий scale-in/flash нового тайла. [A]
5. **Reveal сезона**: волновая раскраска мозаики в полноцветный арт + подъём кубка. [A]
6. Хаптика: success-паттерн на победе, лёгкие тики на сбор кристалла, warning на поражении. [A, по нашим конвенциям]
7. Фоновые амбиент-частицы на игровом экране темы (пылинки/светлячки). [S]

## 9. Структура данных (набросок для интеграции)

```ts
type AdventureObjective =
  | { kind: 'score'; target: number }
  | { kind: 'jewels'; count: number };

type AdventureCellPrefill = { row: number; col: number; jewel?: boolean };

interface AdventureLevel {
  id: number;                 // сквозной номер
  objective: AdventureObjective;
  prefill: AdventureCellPrefill[];
  pieceSeed: string;          // детерминированная генерация
  jewelInPieces?: boolean;    // подмешивать кристаллы в фигуры
  milestone?: boolean;        // красная рамка на мозаике
}

interface AdventureSeason {
  id: number;
  mosaic: { width: number; height: number; tiles: Array<{x:number;y:number; levelIndex:number; milestone?: boolean}> };
  artAsset: string;           // полноцветный reveal-арт
  levels: AdventureLevel[];   // ~90–110
}

interface AdventureProgress {   // MMKV
  seasonId: number;
  levelIndex: number;           // следующий непройденный
  consecutiveClearances: number;
  dailyGoal: { date: string; cleared: number };
  trophies: number[];           // завершённые сезоны
}
```

Движок: цели и предзаполнение — расширение `core/engine` (режим `adventure` в GameConfig: prefill, objective, победа/поражение как события движка), UI-режим — отдельный роут `adventure` + `adventure-level` в `src/app`, фича-модуль `features/adventure`.

## 10. Интеграция с нашими системами

- **Темы**: скин уровня Adventure = наша система тем миров (спека 12); «rainforest» ложится на пайплайн рескинов.
- **Прогрессия (спеки 10–11)**: решить, идут ли очки Adventure в Уровень Игры (рекомендация: да, с коэффициентом, чтобы не ломать баланс спайна).
- **Дейли (спека 14)**: Daily Goal 10 уровней — кандидат в задания дейли-цикла.
- **Монетизация (спека 05)**: ревайв при поражении за rewarded — только за флагом, с учётом анти-чеклиста (спека 06).
- **Капи (спеки 09/15)**: реакции маскота на победу/сезон — опционально, v1.1.

## 11. Открытые вопросы (решить перед реализацией)

1. Семантика Consecutive Clearances: сбрасывать при поражении или в полночь?
2. Награда за Daily Goal — есть ли она в оригинале вообще (на скринах нет)?
3. Идут ли очки Adventure-уровней в общий счёт/Уровень Игры.
4. Что именно на milestone-уровнях (сложность? кристаллы? косметика?) — требуется дополнительный реверс поздних уровней оригинала.
5. Поздние механики-препятствия (лёд/двойные клетки/лимит ходов) — отложить до реверса уровней 50+.
6. Ревайв при поражении: есть ли в оригинале, и нужен ли нам в v1.

## 12. Статус реализации v1: осознанные отклонения и бэклог v1.1

Осознанные отклонения от реверса (зафиксированы, менять только через эту спеку):

1. **Кристалл — PNG-минералы**, а не голубой View-ромб из плана (NFR-9): используется набор из 8 ассетов `assets/adventure/minerals/*` (`features/adventure/assets.ts`), палитра `JEWEL_COLORS` — золотая. Арт-выбор v1; при возврате к ромбу оригинала обновить этот пункт.

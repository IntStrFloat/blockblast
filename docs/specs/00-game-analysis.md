# 00 — Анализ оригинала: Block Blast (Hungry Studio)

Статус: справочный · Обновлено: 2026-06-12
Источник: ресерч-субагент (web-исследование, источники в конце).

## Цифры

- 368 млн загрузок (2025), ~70 млн DAU, #1 по загрузкам 2 года подряд. Россия — топ-6 рынок.
- ~$17.5 млн/мес дохода — **только реклама, IAP нет вообще**.
- Сессия ~12 мин, 2.7 сессий/день. D1 26%, D7 4%.

## Core loop

- Доска 8×8, без таймера, без гравитации.
- 3 фигуры за волну, вращения нет, новая волна после размещения всех трёх.
- Очистка полных строк И столбцов одновременно.
- Game over: ни одна фигура из трея не влезает.
- ~19 базовых форм (моно/домино/тромино/все 7 тетромино/пентомино/2×3/3×3/большие L), ориентации — отдельные фигуры в пуле.

## Скоринг оригинала (community-verified)

- Размещение: **+1 за клетку фигуры**.
- Очистка: **+10 за каждую очищенную клетку** + бонус за число линий одним ходом: 1→10, 2→20, 3→60, 4→120, 5→200, 6+→300.
- **Полная очистка доски: +360.**
- Комбо: каждое подряд идущее размещение с очисткой увеличивает множитель (~+0.5× за шаг); размещение без очистки сбрасывает комбо.
- Мировой рекорд ~1.82 млн очков.

## UX оригинала

- Drag: фигура поднимается над пальцем (~1–1.5 клетки), увеличивается до ~110–120%, ghost-превью валидной позиции, спринг-доводка.
- Очистка: вспышка + частицы, блоки не падают.
- Похвалы: Good → Great → Amazing → Unbelievable.
- Тёмно-синий фон, глянцевые блоки 6–7 цветов со скруглением и объёмом.
- Хаптика: лёгкая при размещении, сильнее при очистке. Спокойная фоновая музыка + короткие SFX.

## Экраны оригинала

Main (Play, Adventure, настройки, high score) · Game (поле, счёт, best, 3 фигуры, **статичный баннер внизу**, пауза) · Game Over (счёт, best, **Revive за rewarded-видео** ~до 3 раз/сессию, New Game) · Adventure (96 уровней, пиксель-арт раскрывается, interstitial после уровня) · Settings (звук/музыка/вибро — всё).

## Монетизация оригинала

| Формат | Где |
|---|---|
| Статичный баннер | низ игрового экрана, постоянно |
| Interstitial | после проигрыша (Classic), после уровня (Adventure) |
| Rewarded | Revive на Game Over |

IAP отсутствуют полностью — даже Remove Ads.

## Retention

Минималистичный мета-слой: win-streak counter без наград, локальный high score, скрытый «God Mode» (после серии проигрышей подсовывает удобные фигуры), Adventure-ивенты. Удержание — качеством core loop (3000+ A/B-тестов механики).

## Выводы для клона (что берём / что меняем)

- Берём: правила 1-в-1, скоринг-формулу, UX drag/превью/похвал, revive за rewarded, цветовую схему.
- Меняем: добавляем IAP «Убрать рекламу» (оригинал не даёт — частая жалоба игроков), дневной стрик, share-карточку, тон похвал — см. [06-audience.md](06-audience.md).
- God Mode не делаем в v1; в движке заложена `trayPolicy` для будущего.
